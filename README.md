## 🚀 Featured projects

### 🇧🇷 [Brazilian exports pipeline](https://github.com/kikzz569/Brasil_exportacoes)

A data-ingestion pipeline for Comex Stat trade data, designed to process more than **10 million records**. It stores raw data in Parquet, performs cleaning and deduplication, and loads the output into PostgreSQL/Supabase.

**Highlights:** Python · Pandas · requests · SQLAlchemy · PostgreSQL · Supabase · Parquet · automated tests · idempotency · rate-limit and timeout handling

### 🏦 [Global banks ETL pipeline](https://github.com/kikzz569/banks_project)

An ETL pipeline that collects data on the world's largest banks by market capitalization, transforms the data, and makes the results available in multiple currencies through SQLite.

**Highlights:** Python · web scraping · data transformation · SQLite · logging

### 🌍 [GDP by country ETL](https://github.com/kikzz569/Country_per_PIB)

An ETL project that extracts nominal GDP data, standardizes values in billions of US dollars, and loads the results into CSV and SQLite while logging every pipeline stage.

**Highlights:** Python · ETL · web scraping · CSV · SQLite · data quality

### 📈 [Ad performance dashboard](https://github.com/kikzz569/EtlProject)

A data-validation and analytics application for advertising campaigns, featuring performance metrics and interactive visualizations.

**Highlights:** Streamlit · Pandas · Plotly · Pydantic · KPI analysis
